# 对照实验说明（审稿意见 #3 的两种回应路径）

> 背景：意见 #3 指出"10 维局部观测不含队友信息，却要求保持编队和避免机间碰撞"，并要求"增加有无队友观测的对照"。
> 本目录提供两条路径：**方案 A（零重训，先做）** 与 **方案 B（重训对照，视 A 的结果决定）**。

---

## 方案 A：零重训诊断（约 10–20 分钟，推荐先做）

**要回答的问题**：奖励里的"编队"与"机间避碰"两项，在实际执行中到底有没有被触发？

**做法**：用**现有 checkpoint**（不改任何训练）在评估时逐 step 统计：

| 指标 | 含义 | 判读 |
|---|---|---|
| `frac_steps_with_interagent_pen` | 有多少比例的步里存在机间距离 < 20 m（奖励 inter-agent 项的触发条件） | **≈0 ⇒ "避免机间碰撞"不是活跃约束**，无人机之间几乎不会靠近 |
| `form_err_mean` / `ideal(37.71)` | 三对机间距离的标准差 ÷ 起始/目标构型自身的标准差 | **远大于 1 ⇒ 编队未被维持**（该项奖励没有产生编队行为） |
| `form_err_first10 → last10` | 首/末 10% 步的编队误差 | 明显下降 ⇒ 在收拢；几乎不变 ⇒ 未收拢 |
| `centroid_d_first10 → last10` | 编队质心到目标质心的距离 | 明显下降 ⇒ 在推进；不变 ⇒ 未推进 |
| `global_min_pair_distance` | 全局最小机间距离 | 决定机间处罚是否曾触发 |

### 运行

```bash
cd /root/autodl-tmp/work
tar -xzf ../patch_对照实验.tar.gz -C .          # 覆盖 uav_env.py / train.py，新增诊断脚本
bash scripts/11_diag_interagent.sh
```
产出 `results/interagent_diag.json`（+ `log_interagent_diag.txt`）。

### 两种可能结果与后续

- **若机间项几乎不触发（≈0）** → 说明"避免机间碰撞"在本任务中基本不是活跃约束、编队也未维持。此时 **#3 可以用"数据否定前提"来回应，方案 B 不必做**。
- **若机间项频繁触发、且编队误差不下降** → 说明奖励确实在要求协同，但观测拿不到队友信息 ⇒ **退化很可能是"部分可观测 + 编队奖励"共同造成**，此时方案 B 值得做（它同时回应 #8 的"机制测量"）。

## 方案 B：队友观测对照重训（视 A 的结果决定；约 2–4 h、¥5–10）

### 预先注册（结果无论正负都如实报告）

| 项 | 设定 |
|---|---|
| 对照条件 | 观测 **10 维**（无队友信息，= 论文主实验） vs **14 维**（加入 2 架队友的相对位置） |
| 算法 | maddpg / matd3 / muav_mtd3 / muav_std3 |
| 种子 | 42、123（非退化种子；资源允许再加 456） |
| 预算与超参 | 1500 episodes/seed，与论文**完全一致，不调参** |
| 评估 | 同一套脚本：分离指标（`eval_metrics_split.py`）+ 机间/编队诊断（`eval_interagent_diag.py`）+ 饱和诊断 |
| **H1** | 加入队友观测后，至少一个种子出现非零**全队到达**（team arrival > 0）或个体到达率显著上升 |
| **H0** | 与 10 维条件无可区分差异 ⇒ 饱和退化**并非**"缺队友信息"所致 |
| 统计口径 | 与论文一致：以训练 run 为单位，报告逐种子值，不使用 episode 级检验 |

### 运行

```bash
cd /root/autodl-tmp/work
export UAV_RESULTS_DIR_TOBS=/root/autodl-tmp/work/results_tobs   # 独立目录，避免与主实验混淆
NPROC=8 bash scripts/12_retrain_teammate_obs.sh
```
> 脚本内部会设 `UAV_TEAMMATE_OBS=1`，并用独立的 `results_tobs/` 存放新 checkpoint（**不会覆盖主实验权重**）。
> 训练支持断点续跑：中断后重跑同一命令即可。

### 实现细节（便于写入论文方法）

- `env/uav_env.py` 新增 `use_teammate_obs` 开关：观测 = 自身状态(4) + 目标相对位置(2) + 最近 2 个障碍相对位置(4) **+ 其余 n−1 架 UAV 的相对位置(2(n−1))** ⇒ 3 架时 **10 → 14 维**。
- 队友信息**仅在观测层加入**，不带通信延迟/丢包（与论文"理想感知"条件对应）；训练与评估协议其余部分不变。
- 对照组（10 维）与论文主实验**完全同源**，因此两组的差异可直接归因于观测内容。

## 交付给谁、交什么

| 输出 | 用途 |
|---|---|
| `results/interagent_diag.json`（方案 A） | 判定"编队/机间避碰"是否活跃约束 → 决定 #3 走"数据否定"还是"补做对照" |
| `results_tobs/metrics_split.json`（方案 B） | 与 `results/metrics_split.json` 直接对照（团队/个体到达、碰撞/安全违反） |
| `results_tobs/interagent_diag.json`（方案 B） | 观测改善后编队与机间项是否变为活跃 |
| 各 `log_*.txt` | 审计与复现证据 |
